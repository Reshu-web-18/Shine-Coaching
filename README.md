# Shine Coaching 🎓

A simple, responsive coaching institute website designed to introduce Shine Coaching, showcase educational programs, highlight student benefits, and help parents contact the institute.

## 📖 About the Project

**Shine Coaching** provides learning support for students from Classes 2–7 and kindergarten students in LKG and UKG. The website presents the institute's teaching approach, available courses, and contact information through a clean and student-friendly interface.

The main goal is to help parents explore courses and learn about the coaching institute.

## ✨ Features

- **Home Page:** Introduction to Shine Coaching and its teaching approach.
- **About Page:** Information about the coaching institute.
- **Courses Page:** Details of available classes and programs.
- **Contact Page:** Contact information for parents and students.
- **Language Selection:** Navigation between Hindi and English pages.
- **Why Choose Us:** Highlights personalized learning, weekly tests, doubt classes, and parent progress reports.
- **Our Programs:** Separate sections for Classes 2–7 and LKG/UKG.
- **Call to Action:** Links that encourage parents to explore courses or contact the institute.
- **Footer:** Quick navigation and institute contact details.
- **Font Awesome Icons:** Icons for contact information and other interface elements.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and visual design.
- **Font Awesome** — Icons for the user interface.
- **Google Chrome or another modern browser** — To view the website.
